# snps-overlapping-exons

To find out which exon contains the most number of SNPs on a chromosome. <br>
This script can also be used to find out several other overlapping features on a chromosome. 


# Workflow:
1. Download BED files Exon and SNP <br>
2. Save files in CSV format <br>
3. Set up an R Script <br>
4. Install libraries <br>
5. Find overlapping regions <br>
6. Calculate the number of overlapping SNPs <br>
7. Save file in BED format <br>
8. Visualize output in UCSC Genome Browser <br>
